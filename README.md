# Automation Lab 6

Учебный проект по автоматизации процессов внедрения и поддержки компьютерных систем. Выполняется в рамках Лабораторной работы №6.

## Описание проекта
Данный репозиторий создан для демонстрации работы с системой контроля версий Git, настройки CI/CD пайплайнов и изучения основ автоматизации развёртывания. Проект содержит примеры конфигурационных файлов для Python-приложения.

## Структура репозитория
- `README.md` — текущий файл с описанием проекта и инструкциями.
- `requirements.txt` — список зависимостей Python, необходимых для работы приложения.
- `.gitignore` — правила исключения временных и служебных файлов из системы контроля версий.

## Ветки проекта
- **`main`** — основная ветка, содержащая стабильную версию проекта.
- **`feature/add-readme`** — ветка для разработки документации. В ней были добавлены первые версии `README.md` и `.gitignore`, а также протестированы механизмы создания Pull Request.
